## 🔒 النسخة الخاصة (سيرفر Coolify — v2)

التطبيق الآن يعمل بوضعين:

| الوضع | متى؟ |
|---|---|
| ☁️ **سيرفر خاص** (Node + SQLite + JWT) | عند النشر على Coolify — دخول بيوزر وباسورد، التوكن محفوظ للأبد، سلال مشتركة وشركاء |
| 📱 **وضع محلي** (LocalStorage) | عند فتح `index.html` مباشرة أو GitHub Pages — للتجربة |

التفاصيل الكاملة للنشر وحفظ البيانات: **[DEPLOY_AR.md](DEPLOY_AR.md)**

```
# تشغيل محلي بالسيرفر
$env:JWT_SECRET="<48 حرف>"; $env:ADMIN_USERNAME="حسن"; $env:ADMIN_PASSWORD="<قوي>"
node server/server.js   # http://localhost:3000
```

## 🚀 التشغيل (وضع محلي/تجريبي)

افتح `index.html` مباشرة في المتصفح — بدون أي build:

```bash
# أو بسيرفر محلي
npx serve .
# أو
python -m http.server 8080
```

ثم افتح: http://localhost:8080

## 📱 الاستخدام

1. **الرئيسية**: شوف الدخل والمصروف والصافي والآمن للصرف + المستحقات العاجلة.
2. **أضف مصروف**: دوس `＋ أضف مصروف` → المبلغ → الفئة → المشروع (توضيب الشقة) → ملاحظة بالتفصيل.
3. **المشاريع**: اعمل مشروع `توضيب الشقة` بميزانية 150,000 → اربط كل مصروف تشطيب بيه → اضغط عليه وشوف كشف الحساب بالقرش.
4. **التذكيرات**: ضيف القسط والإيجار والجمعية بتاريخ الاستحقاق والتكرار الشهري → فلوسي يفكرك قبلها وينقصها من "الآمن للصرف".
5. **التقارير**: اعرف فلوسك راحت فين وصدّر Excel.

## 🛠️ التقنيات

- HTML + TailwindCSS (مبني محليًا `tw.css` — بدون CDN) + Chart.js (محلي `vendor/`) — بدون build للتشغيل
- خط Cairo مستضاف محليًا (`fonts/`) — التطبيق يعمل **أوفلاين بالكامل** بدون أي طلب خارجي
- Vanilla JS + LocalStorage — أوفلاين أولًا (الوضع المحلي)

> عند تعديل كلاسات Tailwind في `index.html`/`app.js`: نفّذ `npm run build:css` ثم ارفع `tw.css` مع التعديل.
- خط Cairo + عربي RTL كامل
- PWA-ready (`manifest.json`)
